# Base de datos

## Modelo ORM
Vamos a ver el concepto técnico, para que Python entienda la bd Django usa un "traductor" llamado **ORM**. Ahora vamos a reemplazar la lista manual que creamos por una base de datos completa.

## Creación de la BD

### 1. Definir estructura
Vamos a abrir nuestro archivo `models.py`, acá es donde definimos lo que vamos a guardar:

```python
from django.db import models

class Curso(models.Model):
    nombre = models.CharField(max_length=200)
    profesor = models.CharField(max_length=200)
    n_alumnos = models.IntegerField()
    descripcion = models.TextField(null=True, blank=True)

    def __str__(self):
        return self.nombre

```
`models.CharField` Se usa para textos cortos, es obligatorio el máximo de caracteres
`IntegerField` Acá solo van números enteros, en caso de que se intente ingresar otra cosa, dará error
`TextField` Se usa para textos largos como párrafos, no necesita declarar un máximo de caracteres. null=True, blank=True, estos datos significan que el campo es opcional, sino nos obligará a escribir algo

`___str___` Es un método mágico de Python que me permite trabajar con textos, se usa para que al momento de querer ver nuestro curso lo muestre por su nombre y no como **<Curso: Curso object (1)>**

### 2. Admin.py
Vamos a hacer visible nuestra tabla desde el archivo `admin,py`, su única función es decirle a Django que debe mostrar la tabla en el panel de control.

```python
class CursoAdmin(admin.ModelAdmin):
    #titulos de las columnas    
    list_display = ("nombre","profesor", "n_alumnos")
    #buscador por nombre
    search_fields = ("nombre",)
    
admin.site.register(Curso, CursoAdmin)
```
Si no pasamos CursoAdmin como segundo argumento, Django ignorará por completo las columnas y el buscador.

Luego de modificar el archivo, debemos escribir estos comandos en la terminal:

```python
1. python manage.py makemigrations
#Crea el plano del cambio hecho en models.py

2. python manage.py migrate
#Aplica el plano en la bd real

3.python manage.py runserver

4. Reiniciar el servidor si es necesario.
```
**Si cambian una sola coma en models.py, deben volver a migrar".**

### 4. Formulario
#### forms.py
Vamos a crear un formulario para que el usuario desde la misma página pueda ingresar los datos, para ello, creamos un archivo `forms.py` en principal es decir. `principal/forms.py`

```python
from django import forms
from .models import Curso

class CursoForm(forms.ModelForm):
    class Meta:
        model = Curso
        #Estos son los campos a llenar
        fields = ['nombre', 'profesor', 'n_alumnos', 'descripcion']
        widgets = {
            'nombre': forms.TextInput(attrs={'class': 'form-control'}),
            'profesor': forms.TextInput(attrs={'class': 'form-control'}),
            'n_alumnos': forms.NumberInput(attrs={'class': 'form-control'}),
            'descripcion': forms.Textarea(attrs={'class': 'form-control', 'rows': 3}),
        }           
```
la clase **Meta** define la base o plantilla de mi formulario
**fields** nos dice que solo los campos puestos acá aparecerán en la página del formulario
**widgets** sirve para inyectar clases CSS como form-control, para que cuando cargue la página, el navegador sepa que debe aplicarle los estilos

#### views.py
Acá deberemos modificar lo que teníamos antes e ingresar esto:
```python
from django.shortcuts import render, redirect
from .models import Curso #tabla creada
from .forms import CursoForm # Importamos el formulario que creamos arriba

def inicio(request):
   #traemos todos los cursos y los guardamos en nuestra variable
   cursos = Curso.objects.all()

    # al apretar guardar o enviar (POST)
   if request.method == 'POST':
    #Crea el formulario
      form = CursoForm(request.POST)
      if form.is_valid():
         form.save()
         return redirect('inicio') #recargamos
   else:
      #si solo entramos a la pag el form va vacío
      form = CursoForm() 
        
    return render(request, 'principal/index.html', {"cursos": cursos, 'form':form})
```
**Una vez cambiado nuestro main por inicio, también deberemos modificar nuestro archivo `urls.py`**

##### Template
En index.html vamos a agregar nuestro formulario
```html
<div class="formulario_contenedor">
    <h3>Registrar Nuevo Curso</h3>
    <form method="POST">
        {% csrf_token %} {{ form.as_p }}  <button type="submit" class="btn_save">Guardar en Base de Datos</button>
    </form>
</div>
```
`{% csrf_token %}` es un código de seguridad en Django, este lo exige siempre al momento de crear un formulario para asegurarse de que los datos son 100% tuyos y no de un externo

`{{ form.as_p }}` Es un atajo, Django genera de forma automática las etiquetas **label** e **input** envueltos en un párrafo **p**
