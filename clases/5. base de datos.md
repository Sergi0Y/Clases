# Base de datos

## Modelo ORM
Vamos a ver el concepto técnico, para que Python entienda la bd Django usa un "traductor" llamado **ORM**. Ahora vamos a reemplazar la lista manual que creamos por una base de datos completa.

## Creación de la BD

### 1. Definir estructura
Vamos a abrir nuestro archivo `models.py`, acá es donde definimos lo que vamos a guardar:

```python
from django.db import models

class Curso(models.Model):
    nombre = models.CharField(max_length=200)
    profesor = models.CharField(max_length=200)
    n_alumnos = models.IntegerField()
    descripción = models.TextField(null=True, blank=True)

    def __str__(self):
        return self.nombre

```
`models.CharField` Se usa para textos cortos, es obligatorio el máximo de caracteres
`IntegerField` Acá solo van números enteros, en caso de que se intente ingresar otra cosa, dará error
`TextField` Se usa para textos largos como párrafos, no necesita declarar un máximo de caracteres. null=True, blank=True, estos datos significan que el campo es opcional, sino nos obligará a escribir algo

`___str___` Es un método mágico de Python que me permite trabajar con textos, se usa para que al momento de querer ver nuestro curso lo muestre por su nombre y no como **<Curso: Curso object (1)>**

### 2. Admin.py
Vamos a hacer visible nuestra tabla desde el archivo `admin,py`, su única función es decirle a Django que debe mostrar la tabla en el panel de control.

```python
from django.contrib import admin
from .models import Curso
# Registro
admin.site.register(Curso)`
```
Luego de modificar el archivo, debemos escribir estos comandos en la terminal:

```python
1. python manage.py makemigrations
#Crea el plano del cambio hecho en models.py

2. python manage.py migrate
#Aplica el plano en la bd real

3.python manage.py runserver

4. Reiniciar el servidor si es necesario.
```
**Si cambian una sola coma en models.py, deben volver a migrar".**
